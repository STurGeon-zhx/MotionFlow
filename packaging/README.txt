MotionFlow Windows 便携版
=========================

1. 请先把整个 ZIP 解压到本机文件夹，不要直接在压缩包内运行。
2. 双击“双击启动 MotionFlow.cmd”，使用期间请保留命令窗口。
3. 浏览器会自动打开 http://127.0.0.1:3001。
4. 单条下载得到 MP4；点击“导出全部”会把所有 MP4 保存到：
   Windows 下载目录\MotionFlow\任务编号
5. 历史任务、上传图片和成片保存在程序旁边的 data 文件夹。
6. 关闭启动命令窗口即可停止 MotionFlow。

系统要求：Windows 10/11 64 位，建议至少 16GB 内存并预留足够磁盘空间。
程序运行或正在渲染时，请勿移动或删除程序文件夹。
