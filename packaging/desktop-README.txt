MotionFlow Windows 桌面版
========================

1. 请先把整个 ZIP 解压到本机文件夹，不要直接在压缩包内运行。
2. 双击 MotionFlow.exe，即可打开可自由调整大小的独立软件窗口。
3. 软件自带桌面运行环境，不会启动 Edge 或 Chrome；关闭窗口后后台服务会自动停止。
4. 单条下载得到 MP4；点击“选择下载位置”后，可把任务内全部 MP4 直接保存到指定文件夹。
5. 历史任务、上传图片和成片保存在程序旁边的 data 文件夹。

系统要求：Windows 10/11 64 位，建议至少 16GB 内存并预留足够磁盘空间；无需安装浏览器或 Node.js。
程序运行或正在渲染时，请勿移动或删除程序文件夹。

软件更新：点击顶部“检查更新”，首次填写 GitHub 发布仓库地址；发现新版后可选择位置下载新版 ZIP。
更新时先关闭软件，解压新版，保留原 data 文件夹以继续使用历史记录。
